# Domain Docs

This is a single-context repo.

Before exploring or implementing, engineering skills should read:

- `CONTEXT.md` at the repo root
- Relevant ADRs in `docs/adr/`

If either path does not exist, proceed silently.

Use the glossary vocabulary from `CONTEXT.md` in issue titles, plans, tests, and implementation notes. If a needed concept is missing, note it as a possible gap for `/grill-with-docs`.

If a proposal contradicts an ADR, surface that conflict explicitly instead of silently overriding the decision.
