Pill-knop in de vaste actiekleur #B84A10; hover wordt #93430B. Gebruik voor "Bestel nu" en andere acties — nooit merkoranje als knopkleur.
```jsx
<Button size="lg">Bestel nu</Button>
<Button variant="secondary">Bekijk het menu</Button>
<Button variant="onDark">Bestel nu</Button> // op inkt-secties
```
Varianten: primary, secondary (omlijnd), onDark (papier op inkt), ghost. Maten sm/md/lg. Tekst altijd in Geist 600.
